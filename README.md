# dashboard-bpsm

Sistem web yang di-deploy di [dashboardbpsm.akmalmarvis.com](https://dashboardbpsm.akmalmarvis.com)

## Tentang Sistem

Repositori ini mengandungi kod sumber dan eksport pangkalan data untuk sistem **dashboard-bpsm**.

## Struktur Projek

```
/db          - Eksport pangkalan data (.sql)
/public      - Fail awam (public access)
.gitignore   - Senarai fail yang dikecualikan
README.md    - Dokumentasi ini
```

## Deployment

- **Hosting:** JimatHosting (nova.ix-dns.com)
- **URL:** https://dashboardbpsm.akmalmarvis.com
- **Stack:** PHP / Laravel
